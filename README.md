# cowork-jobs

Job queue for a browser agent driving Higgsfield generation.

**[`current-job.md`](current-job.md)** is the only file that matters. It holds standing
rules plus one active job, and is rewritten as work changes.

Public **only** because the agent fetching it cannot authenticate. It carries
operational content exclusively — prompts, model settings, and Higgsfield asset IDs
that are inert without an account login. No character bibles, no content strategy, no
story bank; those stay in a private repo.
